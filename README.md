# Verifiable Data Space: JSON-LD contexts and vocabulary

JSON-LD contexts and RDF vocabulary for the Verifiable Data Space (VDS) and the Verifiable Anchor Delegation (VAD), developed by the EUNOMIA project at Universidad Politécnica de Madrid (UPM).

| Resource | Permanent URL | File |
|---|---|---|
| VDS context | `https://w3id.org/eunomia/vds/v1` | `vds-v1.jsonld` |
| VAD context | `https://w3id.org/eunomia/vad/v1` | `vad-v1.jsonld` |
| Vocabulary | `https://w3id.org/eunomia/vds/ns#` | `vocab.html`, `vocab.ttl` |

Always reference the permanent URLs, not the files in this repository. The content of a published version does not change: an incompatible change goes into a new version.
